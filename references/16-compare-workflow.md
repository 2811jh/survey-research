# 多期问卷对比分析工作流程（独立流程，非阶段编号）

> 📌 **何时读取本文档**：用户有两期或以上问卷数据，想对比趋势变化时，由 SKILL.md 指引跳转至此。
> 注意：本流程是多份 CSV 跨期对比，与 `18-drift-workflow.md`（单份问卷按时间/列分桶异动诊断）是不同链路，不复用脚本。

## 触发条件

- 用户有两份不同时期的问卷数据（如两个赛季的满意度调研）
- 用户说"对比一下上两期数据"、"两份问卷的差异"、"这个月和上个月对比"
- 用户想沉淀成月度复用的对比报告

## 执行命令

> ⚠️ **注意**：`scripts/survey_compare.py` 尚未实现。本流程为规划中的能力，下方命令供未来实现参考。如需多期对比，当前可手动用 `crosstab.py` 分别跑两期再人工对比，或用 `survey_drift.py` 做单份问卷的时间分桶异动诊断（见 `18-drift-workflow.md`）。

```bash
python {SKILL_DIR}/scripts/survey_compare.py \
  --files "survey_A.csv" "survey_B.csv" \
  --labels "S21飞龙" "S20X武器" \
  [--mapping "compare_map.json"] \
  [--text_results "text_A.json"] \
  --output_path "survey_compare_报告.xlsx"
```

**参数说明：**

| 参数 | 必填 | 说明 |
|------|------|------|
| `--files` | ✅ | 2~N 份量化 CSV，按**新→旧**排列 |
| `--labels` | ✅ | 各期标签，如 "S21飞龙" "S20X武器"，数量与 --files 一致 |
| `--mapping` | ❌ | 手动题目映射 JSON（见下方格式），不传则纯自动匹配 |
| `--text_results` | ❌ | 各期文本分析 JSON（text_results_xxx.json），数量 ≤ --files 数量，不足的补空 |
| `--output_path` | ❌ | 默认与第一个 CSV 同目录，自动加时间戳 |

## 输出 Excel 结构

| Sheet | 内容 |
|-------|------|
| 📊 指标总览 | 样本量、满意度均分、NPS，含 ▲▼ 趋势标 |
| 📋 逐题对比 | 每道匹配题目的各选项占比 + Δ差值，≥5pp 高亮 |
| 👥 人群结构 | 性别/年龄/职业/段位/游玩情况分布两期对比 |
| 💬 文本主题 | 各文本题的主题维度占比对比（需传 --text_results） |

## 趋势标识规则

| 符号 | 含义 | 触发条件 |
|------|------|----------|
| `▲ +X` | 正向提升 | 均分差 ≥ 0.1，或 pp 差 ≥ 2 |
| `▼ -X` | 负向下滑 | 均分差 ≤ -0.1，或 pp 差 ≤ -2 |
| `▲▲ / ▼▼` | 大幅变化 | 均分差 ≥ 0.5，或 pp 差 ≥ 15 |
| `— 持平` | 无显著变化 | 差值在阈值以内 |

## 手动映射配置（compare_map.json）

适用于跨赛季同题但 Q 编号不同的情况（如 Q13"飞龙满意度" vs Q12"X武器满意度"）：

```json
{
  "manual_pairs": [
    {
      "label": "赛季满意度",
      "a": "Q13.总体而言，您对本赛季【飞龙】赛季的满意度如何？（单选）",
      "b": "Q12.总体而言，您对本赛季【X武器】赛季的满意度如何？（单选）"
    },
    {
      "label": "NPS 推荐意愿",
      "a": "Q51.您有多大可能将《漫威终极逆转》推荐给身边的朋友？（单选）",
      "b": "Q33.您有多大可能将《漫威终极逆转》推荐给身边的朋友？（单选）"
    }
  ],
  "exclude": [
    "Q55.请问您的性别是？"
  ]
}
```

将 `compare_map.json` 保存在数据目录中，**下月只需替换 `--files` 和 `--labels` 参数即可复用**。

## 题目自动匹配策略

1. 去除 `Qxx.` 编号前缀、`（非必填）` 等修饰词后，用 `difflib.SequenceMatcher` 计算字符相似度
2. 相似度 **≥ 0.70** 的题目自动配对
3. 手动映射优先级高于自动匹配
4. 未能匹配的题目在"逐题对比" Sheet 末尾单独列出（标注"仅出现在 A/B"）

## stdout JSON 格式

```json
{
  "status": "success",
  "output_path": "...",
  "matched_questions": 129,
  "unmatched_a_only": 77,
  "unmatched_b_only": 17,
  "sheets": ["📊 指标总览", "📋 逐题对比", "👥 人群结构", "💬 文本主题"]
}
```

## 月度复用建议

1. 每月下载新问卷 CSV 后，直接运行命令（仅替换 `--files` 和 `--labels`）
2. 如题目结构未变，旧的 `compare_map.json` 可继续沿用
3. 如新赛季题目有增减，更新 `compare_map.json` 的 `manual_pairs` 部分
4. 建议按赛季命名保存 `compare_map_S21飞龙.json`，便于追溯

## 错误处理

| 错误 | 原因 | 处理方式 |
|------|------|----------|
| `--labels 数量与 --files 不一致` | 参数个数不匹配 | 检查两个参数数量是否相同 |
| `--text_results 超过 --files 数量` | 传入了多余的文本结果 | 移除多余的 --text_results 参数 |
| 指标总览无数据行 | 问卷无量表题/推荐题 | 正常，该 Sheet 只显示样本量行 |
| 💬 Sheet 未生成 | 未传 --text_results | 需传入至少一期的文本分析 JSON |
