# 月度汇总 Excel

## 触发与边界

固定触发词：**月度汇总 Excel**。用户输入该关键词时，优先进入本分支，而不是下载、Markdown报告或异动显著性分析。

输入：原始CSV/XLSX、明确月份、可选原版模板、输出目录。输出：可用Excel、同名`.audit.json`（映射、样本分母、完整精度、输入hash、逐单元格验收清单）。

- 不需要Excel/WPS，不调用COM、不关闭程序、不解除锁、不删锁文件。
- 其他问卷需要先配置题目和编码。我的世界预置配置也必须预览核对，不把相同数字编码视为跨版本语义保证。
- 不凭题号、相似词或数组顺序推测模板行。`基础性能（卡顿/延迟）`不是`卡顿/延迟`子指标。
- 统计只按显式response_id排除导出尾行；不因单题缺失删除整份答卷，不擅自重复清洗。
- 未配置的指标不虚构；可选题缺失留空、分母0；其他未知值/映射歧义阻断。

## 最短使用方法

脚本位于现有skill的`scripts/survey_excel.py`。先根据用户给定路径生成job JSON，路径相对job解析或使用用户提供的绝对路径。

```cmd
py -X utf8 "{SKILL_DIR}/scripts/survey_excel.py" inspect --input "答卷.csv"
py -X utf8 "{SKILL_DIR}/scripts/survey_excel.py" preview --job "job.json"
py -X utf8 "{SKILL_DIR}/scripts/survey_excel.py" build --job "job.json"
py -X utf8 "{SKILL_DIR}/scripts/survey_excel.py" verify --file "月度汇总.xlsx"
```

所有命令stdout输出JSON；失败`status=error`、退出码1。`preview`不写Excel，但进行真实编码校验和分母计算。输出目录必须已存在；先确认位置再创建目录。

参考`assets/excel/job.example.json`与`assets/excel/minecraft-monthly.json`。不要把示例问卷编码直接用于其他项目。job内`config`可为内联对象或配置JSON路径。

## 工作流程与交付合同

- 读取原始表头，核对月份及清洗说明；一个输入对应一个`YYYY-MM`，重复月份拒绝。一个月多文件需要先明确去重合并策略，本版不自动合并。
- 用`inspect`检查列；用`preview`列出每月每指标唯一列、人群编码、有效分母和缺失数。
- 映射歧义、题目变化、非法编码、缺少必需题时先补配置，不修改脚本猜测、不绕过校验。
- `build`默认新建标准工作簿；已有目标时拒绝。用户明确授权覆盖后才用`--overwrite`，工具先生成时间戳备份。
- 先生成同目录临时文件，所有写入单元格与格式回读通过，才原子替换Excel；验证报告作为sidecar保存。磁盘/权限错误必须报告，不能声称成功。
- 交付前必须执行`verify`；只有status=verified才可说通过。用户后续手动编辑会导致hash变化，此时原审计不再证明当前文件。
- Excel-only请求到此交付，不自动生成Markdown业务报告。JSON报告含汇总数据，不含个人原始答卷；仍应按内部研究数据管理。

## 两种模式

### 新建标准月报

job不填`template`。生成：`月度指标`、`有效样本`、`环比变化`、`口径与映射`。

- 指标×人群逐行，月份逐列。环比只有连续相邻自然月才计算；缺月不伪称环比。
- 均值差值为分数差；NPS/占比差值为百分点pp，不把相对变化混入。
- 数值不提前round；Excel双精度存储，显示2位；样本量为整数。
- 月份明确文本`2026年11月`，不是日期序列号。
- 均值按配置allowed最小/最大值的固定色阶，NPS固定−100%至100%，占比固定0–100%中性数据条。
- 已知方向才对差值着色：higher指标上升绿；lower问题指标上升红；neutral不评价。规则不包含标题、样本量、分隔空行，颜色不表示显著性。

### 保留模板更新

job填`template`和`bindings`，或明确`append_only:true`。

`append_only`：原模板各表完全保留，追加统一的新月度明细4表；这是安全默认，不声称已经重写旧表中的本期月份或旧条件格式。

`bindings`：通过sheet、主标题、标题列、月份表头定位唯一目标。`column`可限定重复月份比较列，但该列必须有匹配月份表头。值只写已确认单元格，同时更新其月份文字和数字显示格式；原字体/填充/边框不变。公式目标拒绝覆盖。

- 标题在多个表块重复时必须通过`row_range:[起始行,结束行]`限定已核对表块，再按主标题唯一定位；该范围是校验边界而非硬编码某行写入。未提供范围且匹配多行时停止。不支持任意复杂模板全自动迁移。
- 模板没有新月份表头时不猜空位、不插行列；改为明确append_only承载新月，或经确认准备新版模板。
- 全部原历史及未知OOXML部件保留；新4表再生成时输入必须覆盖其既有全部月份，漏月份拒绝，避免滚动丢失历史。
- 保留用户原表条件格式；统一规则作用于新生成4表。若用户要求修复原表规则，应先列出原规则并取得明确范围，不宣称“原表全部规则已重建”。
- 刷新可解析的本地矩形单元格图表引用缓存，不更改外部/复杂公式图表；不能将无法支持的图表宣称已验收。原图样式和位置保留。
- 未触碰部件字节保真核对；原表行高、列宽、隐藏属性校验；不要用openpyxl整本重存用户模板，以免丢WPS扩展或特殊图表。

## 统计配置

`metrics`每项：`id`、唯一`label`、`kind`（mean/nps/proportion）、`match`、`direction`。

`match`支持`exact`、`contains`列表（全部满足）、`exclude`列表、`suffix`、`regex`，组合为AND。不允许“找到第一个就用”。

均值/NPS需显式`allowed`编码；NPS必须0–10。多选需`selected`、`unselected`（互斥），分母必须配置：

| mode | 定义 | 适用 |
|---|---|---|
| all | 全组有效答卷 | 明确问所有人的多选 |
| answered | 同题任一选项有记录 | 1/空、0/1导出，必须核对系统对未答和未选编码 |
| eligible | 指定资格列的配置值 | 门控追问、有独立资格字段 |

1/空导出不能区分“未答”和“全不选”时不要装作可以区分，应记录限制或提供资格列。0不是已选。缺失不转零分。

`groups`每项显式`match`、`allowed`和`values`。工作人群含哪些职业必须配置，不自动将“其他”或“不愿透露”当工作人群。

## 故障处理

- 锁文件/只读：请用户手动关闭或另存，不尝试另进程绕过锁。
- 编码未知：问卷选项编码表核对后更新配置，记录版本变化。
- 重复字段：收紧匹配，不选择第一列。
- 验收失败：保留原文件，输出原因，不继续发布。
- 未知模板：用标准新建或append_only；不得把前次项目的行号硬编码到通用代码。
- 下次使用示例：“月度汇总 Excel，用这些原始答卷和月份，按这个模板，输出到这个目录。”
