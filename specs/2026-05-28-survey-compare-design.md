# 设计文档：多期问卷对比分析工具 (survey_compare.py)

**日期**：2026-05-28  
**状态**：待实施  
**目标**：让 survey-research skill 支持跨赛季/跨版本的问卷数据横向对比，每月可复用

---

## 1. 背景与目标

每个游戏赛季结束后，运营团队会下载新一期满意度问卷数据。现有工具只支持单份问卷分析，无法直接对比"S21飞龙赛季" vs "S20X武器赛季"等跨期变化。

**目标**：
- 生成多期问卷对比 Excel，4 个 Sheet，涵盖关键指标趋势、逐题对比、人群结构、文本主题变化
- 工具沉淀进 survey-research skill，通过 CLI 命令月度复用
- 支持 2~N 份问卷对比（通常为相邻两期，也可三期并排）

## 3. CLI 接口

```bash
python survey_compare.py \
  --files "survey_A.csv" "survey_B.csv" \
  --labels "S21飞龙" "S20X武器" \
  --mapping "compare_map.json" \
  --text_results "text_A.json" "text_B.json" \
  --output_path "对比报告.xlsx"
```

### 参数说明

| 参数 | 必填 | 说明 |
|------|------|------|
| `--files` | ✅ | 2~N 份量化数据 CSV，按时间**新→旧**排列 |
| `--labels` | ✅ | 对应标签，如 "S21飞龙" "S20X武器" |
| `--mapping` | ❌ | 手动题目映射 JSON（见第 5 节），不传则纯自动 |
| `--text_results` | ❌ | 各期文本分析 JSON（text_export 的 results_file），按顺序对应 --files |
| `--output_path` | ❌ | 默认 `survey_compare_{timestamp}.xlsx`，保存在第一个 CSV 同目录 |

### stdout 输出 JSON

```json
{
  "status": "success",
  "output_path": "...",
  "matched_questions": 42,
  "unmatched_a_only": 8,
  "unmatched_b_only": 5,
  "sheets": ["指标总览", "逐题对比", "人群结构", "文本主题"]
}
```

## 4. 四个 Sheet 设计

### Sheet 1：📊 指标总览

| 指标名 | S21飞龙 | S20X武器 | 趋势 | 备注 |
|--------|---------|----------|------|------|
| 样本量 | 6,176 | 7,891 | — | |
| 整体满意度均分 | 3.58 | 3.43 | ▲ +0.15 | Q1/Q2 量表题 |
| NPS | 12.3 | 9.8 | ▲ +2.5pp | |
| 不满意率 | 18% | 23% | ▲ 改善 | |
| ... | | | | |

**趋势标识规则**（对齐截图中已有的样式）：
- `▲ +Xpp` / `▲ +X分`：正向提升，绿色
- `▼ -Xpp` / `▼ -X分`：负向下滑，红色
- `— 持平`：灰色（差值 < 2pp / 0.1分）
- `▼▼ 降幅剧烈`：差值 > 15pp，橙红色 + 备注"样本量小，参考意义有限"

指标来源：自动从 `basic_stats.py` 的输出逻辑提取量表题均分和 NPS。若未跑过 basic_stats，则在脚本内部临时计算。

---

### Sheet 2：📋 逐题对比

每道**可匹配**的题目一行（按匹配题目的 Q 编号排序）。

列结构：

| 匹配题目（去前缀） | 选项 | A 期占比 | B 期占比 | Δ (A-B) | 是否显著变化 |
|-----------------|------|---------|---------|---------|-----------|
| 整体满意度 | 非常满意(5) | 22% | 18% | +4pp | ✅ |
| 整体满意度 | 比较满意(4) | 35% | 32% | +3pp | |
| ... | | | | | |

- 每道题占多行（每个选项一行），题目名仅第一行显示，其余合并单元格
- `Δ > 5pp` 高亮（正向绿，负向红）
- 末尾追加"仅出现在 A" 和 "仅出现在 B" 的题目清单

---

### Sheet 3：👥 人群结构对比

对性别、年龄、职业、段位等人口学/行为变量，对比两期分布。

| 维度 | 选项 | A 期 | B 期 | Δ |
|------|------|------|------|---|
| 性别 | 男 | 72% | 70% | +2pp |
| 性别 | 女 | 28% | 30% | -2pp |
| 年龄 | 18-24 | 35% | 38% | -3pp |
| ... | | | | |

识别方式：列名含「性别」「年龄」「职业」「段位」「游玩」关键字的单选题。

---

### Sheet 4：💬 文本主题变化

**仅当 `--text_results` 有传入且两期都有对应 JSON 时生成此 Sheet。**

每道可匹配的文本题一张小表：

```
题目：您对当前游戏体验不满意的原因是？
─────────────────────────────────────────
主题          A期(S21) 占比    B期(S20) 占比    变化
环境固化/卡组单一  28.9%           31.2%          ▼ -2.3pp
闪退/性能问题     24.2%           18.5%          ▲ +5.7pp（恶化）
卡牌获取难        18.6%           22.1%          ▼ -3.5pp（改善）
...
```

若某期某题没有文本数据，标"本期未分析"。

## 5. 题目匹配策略

### 自动匹配

1. 提取所有列名，去除 `Qxx.` 前缀、去除「（非必填）」等括号、去除空白
2. 用 `difflib.SequenceMatcher` 计算字符相似度
3. **阈值 ≥ 0.70** 视为同一题，取最高相似度的配对
4. 多选题的子列按根题配对（同根则归入同组）

### 手动映射 JSON（`compare_map.json`）

```json
{
  "manual_pairs": [
    {
      "label": "整体满意度",
      "a": "Q1.请问您对游戏的整体体验满意度如何？",
      "b": "Q1.请问您对游戏的整体体验满意度如何？"
    },
    {
      "label": "赛季满意度",
      "a": "Q13.总体而言，您对本赛季【飞龙】赛季的满意度如何？",
      "b": "Q12.总体而言，您对本赛季【X武器】赛季的满意度如何？"
    }
  ],
  "exclude": [
    "Q55.请问您的性别是？"
  ]
}
```

- `manual_pairs` 中的映射**覆盖**自动匹配结果
- `exclude` 中的列从逐题对比中排除（仅保留在指标总览/人群结构里）
